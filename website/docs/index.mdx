# Iskra

**Iskra** (Bosnian for *spark*) is a self-improving AI agent — a surface-rebranded fork of
[Hermes Agent](https://github.com/NousResearch/hermes-agent) by Nous Research. It is not a coding
copilot tethered to an IDE or a wrapper around one API: it is an **autonomous agent** that gets more
capable the longer it runs. It creates skills from experience, improves them during use, nudges itself
to persist knowledge, and builds a deepening model of who you are across sessions.

It lives wherever you put it — a $5 VPS, a GPU cluster, or serverless infrastructure that costs nearly
nothing when idle — and you talk to it from Telegram, Discord, or the CLI while it works.

## Install

### Linux / macOS / WSL2

```bash
curl -fsSL https://ockentap.github.io/iskra-agent/install.sh | bash
```

### Windows (native)

Run in PowerShell:

```powershell
iex (irm https://ockentap.github.io/iskra-agent/install.ps1)
```

For aarch64 Android devices, use the separate [Termux APT guide](./getting-started/termux.md). See the
full **[Installation Guide](./getting-started/installation.md)** for what the installer does, data
locations, and platform notes, and **[Platform Support](./getting-started/platform-support.md)** for the
support matrix.

:::tip Fastest path to a working agent
After installing, run `iskra setup` to pick a model and start talking. See
[Configuration](./user-guide/configuration.md) for providers and endpoints.
:::

## Key Features

- **A closed learning loop** — agent-curated memory with periodic nudges, autonomous skill creation,
  skill self-improvement during use, and FTS5 cross-session recall.
- **Runs anywhere** — 6 built-in terminal backends (local, Docker, SSH, Daytona, Modal, Vercel Sandbox)
  plus plugin backends. Serverless options hibernate when idle, costing nearly nothing.
- **Lives where you do** — CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Email and more —
  20+ platforms from one gateway.
- **Scheduled automations** — built-in cron with delivery to any platform.
- **[Bot Mode](./user-guide/bot-mode.md)** — a durable team of specialist Bots that collaborate through
  `@mentions`.
- **Delegates & parallelizes** — spawn isolated subagents for parallel workstreams.
- **Open standard skills** — compatible with [agentskills.io](https://agentskills.io); portable and
  shareable.
- **MCP support** — connect any MCP server for extended tool capabilities.

## Fork notes

Iskra is a **surface rebrand**: internal module names, `HERMES_*` environment variables, config keys and
the database schema are unchanged, so it merges upstream Hermes cleanly and loads existing Hermes skills
and plugins. The default data directory is `~/.iskra`; set `HERMES_HOME=~/.hermes` to share an existing
Hermes install. Upstream copyright is retained in `LICENSE` (MIT).
